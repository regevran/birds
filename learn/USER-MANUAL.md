# Birds trainer — user manual

Learn the Latin names of Israeli birds from Hebrew.
Sign in with your account.
Progress is saved online. There is no timer.

## Sessions

A session is a saved practice list.
Sessions are created from search results.

Examples:

- `Acrocephalus` — the genus.
- `warbler` — English text.
- `Anatidae` — the family.
- `Passeriformes` — the order.

`default` holds every bird you can practise. It cannot be renamed or deleted.

Each bird has a fixed card order:

`L → E → R → C → F`

Without name parts:

`L → R → C → F`

Cards are added as you progress. The order never changes.
A session is complete when every bird has finished its chain.

## Cards

| | Card | What you do |
|---|---|---|
| (L) | Learn | Read the name, parts and picture. Next. |
| (E) | Elements | Match each part to its meaning. |
| (R) | Recognize | Choose the Latin name. |
| (C) | Construct | Type the Latin name with hints. |
| (F) | Produce | Type the Latin name. |

- E always moves on. Its score is feedback.
- R/C/F: one retry, then the answer is shown.
- A near miss shows the spelling and moves on.
- F completes the bird.

## Card runs

A card run is a one-off practice from a search. Nothing is saved.

Example:

1. Search `Acrocephalus`.
2. Choose `Recognize`.
3. Every match gets one R card, in search order.

Birds that cannot make the card are skipped.

## Search

Search by Latin, English or Hebrew name, family, order, or a part's meaning.
Select a result to see the bird, its parts and its picture.

Card buttons: a card run over all results.
Panel buttons: a card run from one part.
`Session`: a saved session.

## Practising

The large card is the current one.
The strip shows completed and planned cards.

## Progress

The percentage counts birds that have finished their chain.
100% means the session is complete.
