# Third-party illustrations

The bird illustrations served by the browser client are derived from
[huashu-bird-sticker](https://github.com/alchaincyf/huashu-bird-sticker)
(CC BY 4.0). The repository is pinned in `illustrations.json`; the build
downloads only the 565 stickers used by this trainer.

Required credit:

> Illustration: Bird Album (birdalbum.com) / huashu-bird-sticker, CC BY 4.0

- Licence: <https://creativecommons.org/licenses/by/4.0/>
- Changes made here: each sticker is downscaled to 512 px on its longest side
  and re-encoded as WebP (quality 82). Alpha transparency is preserved.
- The images are AI-generated according to the source project and are not
  expert-verified; they are used as recognition aids, not as field-guide
  references.
- For species the source taxonomy lumps (for example Hooded Crow, which shares
  the Carrion Crow sticker, and the split swamphens), one sticker may represent
  more than one dataset species.
